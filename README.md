# Ridge Trades

Mountain-state general contractor landing. Navy, safety amber, and concrete. Light-custom: logo, colours, fonts, copy, and section on/off.

Live demo: https://ridge.little.website/

## Features

- Mountain-state general contractor landing
- Light-custom: logo, colours, fonts, and copy
- Section on/off for hero, trades, projects, process, area, and contact
- Navy, safety amber, and concrete palette
- Industrial condensed display type
- Fully responsive Astro SSG

## Design

Typography:
- display: Barlow Condensed
- body: Source Sans 3

Colors:
- Navy: #0b1d33
- Safety amber: #f0b429
- Concrete: #e6e2d8
- steel: #4a5560

## Customization

Light-custom: logo, colours, fonts, copy, and section on/off.

Edit src/data/site.ts and CSS variables in src/styles.

Page sections:
- Hero
- Trades
- Projects
- Process
- Area
- Contact

Use cases:
- General contractors
- Trade businesses
- Construction firms
- Regional builders
